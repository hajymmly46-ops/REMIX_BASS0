REMIXBASS0 — قالب اولیه سایت دانلود موزیک

شروع:
1) فایل ZIP را از حالت فشرده خارج کن.
2) برای پیش‌نمایش، index.html را در مرورگر باز کن.
3) آهنگ‌های مجاز برای انتشار را داخل پوشه assets بگذار.
4) فایل script.js را باز کن و آرایه tracks را مانند نمونه پر کن:
   { title: "اسم آهنگ", artist: "نام خواننده/دی‌جی", category: "ریمیکس", file: "assets/song.mp3" }

لینک کانال از قبل روی https://t.me/REMIX_BASS0 تنظیم شده است.

نکته مهم:
این نسخه یک قالب فرانت‌اند اولیه است. دکمه دانلود ابتدا کاربر را به کانال هدایت می‌کند و سپس با زدن «برگشتم؛ ادامه دانلود» دانلود را آغاز می‌کند؛ عضویت واقعی را بررسی نمی‌کند.
برای اجبار واقعی عضویت، باید ربات تلگرام به‌عنوان ادمین کانال اضافه شود و یک بک‌اند/سرور برای بررسی getChatMember و تحویل لینک دانلود پیاده‌سازی شود.
برای انتشار عمومی سایت نیز به هاست و دامنه نیاز است.
